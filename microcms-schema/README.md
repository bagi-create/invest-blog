# microCMS API設定

いちばん簡単なのは、サービス作成時に **「ブログ」テンプレート** を選ぶ方法です。
`blogs`（記事）と `categories`（カテゴリ）が自動で作られるので、足りないフィールドと `tags` API を追加するだけです。

## 1. categories（リスト形式 / エンドポイント: `categories`）

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| name | カテゴリ名 | テキストフィールド | ✓ |
| description | 説明 | テキストエリア | |

> **コンテンツIDをURLにします。** カテゴリ作成時、コンテンツIDを `nisa` `ideco` `fund` `us-stock` `household` のように半角英数で手動設定してください（`src/config.ts` のナビと一致させる）。

## 2. tags（リスト形式 / エンドポイント: `tags`）

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| name | タグ名 | テキストフィールド | ✓ |

## 3. blogs（リスト形式 / エンドポイント: `blogs`）

| フィールドID | 表示名 | 種類 | 必須 | 備考 |
|---|---|---|---|---|
| title | タイトル | テキストフィールド | ✓ | テンプレートに既存 |
| description | 概要（meta description） | テキストエリア | | 120字前後推奨 |
| content | 本文 | リッチエディタ | ✓ | テンプレートに既存 |
| eyecatch | アイキャッチ | 画像 | | テンプレートに既存。1200×630推奨 |
| category | カテゴリ | コンテンツ参照（categories） | | テンプレートに既存 |
| tags | タグ | 複数コンテンツ参照（tags） | | |
| isPr | PR（広告を含む） | 真偽値 | | ONで記事冒頭にPR表記を自動表示 |

> 記事のコンテンツIDもURL（`/posts/<ID>/`）になります。`nisa-basics` のような英数スラッグを手動設定するのがおすすめです。

## 4. APIキー

「API キー」画面で **GET権限のみ** のキーを使います（デフォルトキーでOK）。書き込み権限は不要です。

## 5. Webhook（記事公開で自動再ビルド）

各API（blogs / categories / tags）の「API設定 → Webhook → カスタム通知」に、Cloudflareで発行した **Deploy Hook URL** を登録。
通知タイミングは「コンテンツの公開・公開終了・削除」をONにします。
